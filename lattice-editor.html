Lattice editor

Start from the carrier lattice, click segments to colour them, save the design as SVG (and JSON to reload or to feed the weave app).

Lattice

Extra tie points between two crossings: each vertical (or diagonal) segment is split into that many paintable pieces, and every tie point gets a dot. Click a dot to start a free line, move, and click another dot to place it — a straight cable between any two anchors. A second line between the same two anchors sits beside the first. Clicking a line with its own colour deletes it; another colour recolours it. esc cancels a line in progress.

Rebuilding keeps colours where the segment ids still match (same kind, pitch and anchors).

Paint

Distance between colours on the same segment or between the same two anchors: the first sits on the line, the next ones this far to either side. 0 stacks them.

Click a segment to paint it with the selected colour; another colour on the same segment sits beside it (see the offset below). Drag to paint many. shift-click paints the whole line. Clicking with a colour the segment already has takes that colour off; the eraser clears the segment. z undo, 1–6 colours, 0 eraser.
